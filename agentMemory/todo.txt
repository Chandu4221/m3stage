## P0 – Trust (data safety and correct output)

Exit gate M1 "Trustworthy": a user can design, quit, relaunch, and find their work intact; exported code compiles; nothing crashes on bad input.

- [ ] TODO-13 (1): Durable persistence. Autosave (debounced ~500 ms), save on window close, atomic write (temp file + fsync + atomic move), `Mutex` around saves, save-failure surfaced to the user, dirty indicator.
  - Accept: kill -9 during save never corrupts the file; reopen restores state; test with injected failing repository.
- [ ] TODO-14 (2): Strict, versioned file format. Add `schemaVersion`; migration chain; unknown component kind or unknown `DevicePreset` id fails the load (never defaults to `Box`/Pixel 8); preserve unknown fields; stop DTOs from embedding domain enums (use string ids with explicit mapping); cap quarantine backups; report backup-copy failure honestly.
  - Accept: loading a file from a "newer" version leaves the file untouched and shows a clear error.
- [ ] TODO-15 (3): Compilable codegen. Icon allowlist enum with correct `MemberName` imports (no raw strings in code); Image placeholder fixed; unique file and function names across all screens; ktfmt failure becomes a reported error instead of silent fallback; omit unneeded `@OptIn`.
  - Accept: generated output for every `ComponentKind` compiles in CI (kotlin-compile-testing or a fixture Gradle project).
- [ ] TODO-16 (4): Export hardening. Validate package name in the dialog and in the domain (including Kotlin keywords); move `copy(...)` inside error handling; native Save dialog; no silent overwrite; show real generated file names; catch `IllegalArgumentException`; never throw on the UI thread.
- [ ] TODO-17 (5): Preview/export parity contract. One shared layout-defaults object used by both renderer and codegen (fillMaxWidth, padding, TextField variant, Icon tint, Button text color, spacing + arrangement semantics, null-shape behavior). Selection wrapper must not alter layout.
  - Accept: golden tests per kind; a test fails if renderer and codegen disagree.
- [ ] TODO-18 (6): Engineering floor. GitHub Actions (build, test, `check` on Linux/macOS/Windows), LICENSE file, `.editorconfig`, ktfmt/spotless + detekt in `check`, branch protection, delete `agentMemory/` from the repo.

## P1 – Core product (what a user expects from a builder)

Exit gate M2 "Usable": a user can build a realistic multi-screen UI with only the mouse and keyboard and export it.

- [ ] TODO-19 (7): Property Inspector generated from `ComponentCatalog[kind].descriptors`, grouped by `PropertyGroup`. Editors for text, switch, dp slider, enum, color (token + custom), typography, shape. Emits `UpdatePropCommand`; coalesce drag/typing into one undo step; show/reset to default.
- [ ] TODO-20 (8): Domain-enforced structure. `canAccept(parent, child)` from `allowedChildren`/`isContainer`; mutations return a result instead of silent no-ops; `HistoryDelegate` ignores no-op commands; selection reconciled after undo/redo/delete; reject invalid drops with visible feedback; typed property values (validate type per key).
- [ ] TODO-21 (9): Node operations. Delete, duplicate, copy/paste (across screens), move/reorder (up/down), wrap-in, hide/show, rename. Undo for all (fix `RemoveNodeCommand` to restore the original index).
- [ ] TODO-22 (10): Layers/tree panel with selection sync, drag-reorder, visibility and lock toggles; fix canvas selection of Button/TextField (intercept pointer events in the Initial pass or use a selection layer above the content).
- [ ] TODO-23 (11): Drag-and-drop from palette to canvas and tree with insertion indicators; click-to-add stays as fallback.
- [ ] TODO-24 (12): Real shortcuts: undo/redo, delete, duplicate, copy/paste, zoom, tools (V/H/Space), save, export. Single shortcut registry that also feeds tooltips (remove tooltips for unimplemented keys).
- [ ] TODO-25 (13): Project lifecycle. New/Open/Save As/Recent, project name and base package editable and persisted, multi-project support, unsaved-changes prompt, screen rename/delete/duplicate/reorder.
- [ ] TODO-26 (14): Theming that matches Compose. Wire seed color picker (custom hex + presets), light/dark preview side by side, export `Color.kt`/`Theme.kt`/`Type.kt`; separate studio chrome theme from the design theme.
- [ ] TODO-27 (15): Make device state part of the document: persist `Screen.device`, honor `Project.defaultDevice`, orientation/frame state saved; undoable.

## P2 – Engineering soundness (so features stop breaking each other)

Exit gate M3 "Solid": refactors are safe because tests catch regressions; large projects stay responsive.

- [ ] TODO-28 (16): Resolve `children` vs `slots`. Choose one model (recommended: named slots for Scaffold/TopAppBar, children elsewhere, enforced in queries/mutations/validation/renderer/codegen) or delete slots.
- [ ] TODO-29 (17): `NodeFactory` in `:domain` for default anatomy (Scaffold, Button+Text, Card). Remove the three duplicate genesis implementations.
- [ ] TODO-30 (18): Typed options. Carry domain option enums through `PropertyValue` (no `EnumValue(name: String)` + string `when` tables); one mapping per target (preview, codegen).
- [ ] TODO-31 (19): Performance. Structural sharing in tree mutations (return same instance when unchanged); stable/immutable annotations; benchmark 20 screens x 500 nodes; avoid re-rendering inactive artboards when off-screen; cursor-anchored zoom.
- [ ] TODO-32 (20): Decouple concerns. Move bezel details (corner radius, notch) out of `DevicePreset`; stop exposing mutable flows in `EditorContext`; replace `SharedFlow` events with a buffered `Channel` or replay so events are never dropped; inject dispatchers.
- [ ] TODO-33 (21): Test strategy. Store/History/Session tests (fake repo, test dispatchers); renderer tests (compose ui-test); property-based tree tests (mutations preserve invariants); round-trip fuzz over all kinds and value types; migration tests; coverage report in CI with a floor.
- [ ] TODO-34 (22): Dead code purge. Remove `TopProjectAppBar`, `ComponentsPalettePanel`, `InspectorPanel`, `AlignmentMatrix`, `DotMatrixCell`, `SegmentedButtonGroup`, `ColorSwatch`, `AddScreenGhostCard`, commented stubs in `NodeQueries.kt`, or wire them (decide per item). Remove stub rail tabs until implemented.
- [ ] TODO-35 (23): Observability. Structured logging instead of `System.err`; global uncaught-exception handler with user-visible report dialog; crash log file; do not swallow `CancellationException`.
