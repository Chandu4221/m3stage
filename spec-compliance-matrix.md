# Material 3 Spec-Compliance Audit Matrix

Authoritative audit covering all 25 `ComponentKind` definitions registered in `ComponentCatalog.all`.
Conducted by direct code inspection across domain definitions, Compose renderer implementations, and Compose code generators.

## Summary of Findings & Resolutions

1. **Card ContainerColor**: Previously declared with hardcoded definition-level default (`Surface`) and completely unconsumed in `CardRenderer` (DEAD prop).
   - **Resolution**: Definition default updated to `M3ColorToken.Inherit` (unset). `CardRenderer` wired to `CardDefaults.cardColors(containerColor = ...)` only when explicit. `CardCodegen` wired to emit `colors = CardDefaults.cardColors(...)` only when explicit.
2. **NavigationBarItem Fallback & Icons**: Previously used an unweighted `Row` fallback causing bunching/shrinking when `LocalRowScope` was absent, and hardcoded `Icons.Default.Star` with `contentDescription = null`.
   - **Resolution**: Replaced with weighted `Row` + `Modifier.weight(1f)` fallback to maintain even spacing. Replaced fallback icon with `Icons.Default.Add` + `contentDescription = "Add"`.
3. **Text Overflow**: Declared in `TextDefinition.kt` (`TextDefinition.Overflow`), but unconsumed in both `TextRenderer` and `TextCodegen` (DEAD prop).
   - **Resolution**: Wired `TextRenderer` to Compose `TextOverflow` (`Ellipsis`, `Visible`, `Clip`). Wired `TextCodegen` to emit `overflow = TextOverflow.Ellipsis / Visible` when non-default.
4. **TextField Slots**: `LeadingIconSlot`, `TrailingIconSlot`, and `SupportingTextSlot` were declared in `TextFieldDefinition.kt`, but unconsumed in `TextFieldRenderer` and `TextFieldCodegen` (divergence from `OutlinedTextField`).
   - **Resolution**: Wired `leadingIcon`, `trailingIcon`, and `supportingText` slot rendering and codegen in `TextField`, establishing full parity with `OutlinedTextField`.
5. **Column, Row, Box Alignment & Arrangement**: `ColumnDefinition` (`HorizontalAlignment`, `VerticalArrangement`), `RowDefinition` (`HorizontalArrangement`, `VerticalAlignment`), and `BoxDefinition` (`ContentAlignment`) were defined in domain but unconsumed in renderers and codegen (DEAD props).
   - **Resolution**: Wired all alignment and arrangement properties in both renderer and codegen for `Column`, `Row`, and `Box`, respecting item spacing and Compose layout defaults.
6. **Selection Control Booleans**: `SwitchRenderer`, `CheckboxRenderer`, and `RadioButtonRenderer` (and their codegens) fell back to `?: true` for unpopulated boolean states, while domain definitions defaulted to `false`.
   - **Resolution**: Corrected fallbacks to `?: false` matching definition defaults.
7. **IconButton & FAB Fallbacks**: Empty `IconButton` fell back to `Text("★")`, and `FloatingActionButton` fell back to `Text("+")`.
   - **Resolution**: Replaced with `Icon(imageVector = Icons.Default.Add, contentDescription = "Add")` across renderers and codegen.
8. **Image Fallback**: Null `contentDescription` fallback in `ImageRenderer` and `ImageCodegen` now defaults to `"Image"` matching definition default for accessibility compliance.
9. **Color Invariant Verification**: Added living automated tests `CatalogColorInvariantTest.kt` in `:domain` and `CatalogColorResolutionTest.kt` in `:adapter:compose-renderer` asserting that all 25 catalog definitions default to `M3ColorToken.Inherit` and resolve to `Color.Unspecified` when unset.
